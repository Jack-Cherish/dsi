BAUHAUS STUDIO

在房间里，自由布置。

样板间模式可以自由走动。按住 WASD 或屏幕方向键移动，拖动空白处转头，滚轮前后移动。

放置模式：拖动物品改变位置；右键拖动转头。V 拖放、G 坐标轴、R 旋转、H 升降。也可直接输入 X / Y / Z 和角度。Delete 收回家具，Ctrl+Z 撤销。

样板间与放置模式使用同一套实时画面。切换样板间会保留你的布置；返回放置模式可继续。只有“一键还原”会替换当前布置，仍可撤销。

原图宽 7510 mm；沿用方案 B 的主卧后置、书房兼客卧布局。厨房固定设施为建筑陈设示意；物品库含全部原包豪斯候选及新增京东陈设。场景为方案模型，不是施工图或厂商精确模型。

颜色与夜间灯光按参考图呈现；实时环境反射和间接光为近似，不等同于离线光线追踪。

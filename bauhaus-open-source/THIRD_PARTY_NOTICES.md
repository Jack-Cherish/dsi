# 第三方素材与许可证范围

本地完整包为了复现现有页面而保留第三方参考素材；本文件不替素材权利人授予许可。

| 范围 | 来源／许可记录 | 使用说明 |
| --- | --- | --- |
| `src/`、构建与检查脚本、原创文档 | 本项目，MIT | 可按根目录 LICENSE 使用与修改 |
| Three.js 0.180.0 | MIT，见 `licenses/three-LICENSE.txt` | 打包进最终 JS，保留许可声明 |
| esbuild 0.25.11 | MIT，见 `licenses/esbuild-LICENSE.txt` | 开发构建工具；不需要在最终网页运行 |
| `public/assets/*.jpg` | 采集记录标为 Poly Haven CC0，逐项来源见 `public/assets/sources.json` | 来源 URL 与贴图类型已保留；本次打包没有重新在线核验 |
| `public/products/*` | IKEA、京东商家、品牌商品页等 | 商品图版权归原权利人；未确认统一再分发许可，不属于本项目 MIT |
| 品牌、商品名称与造型 | 相应品牌／设计者 | 仅用于识别与布局参考，不表示品牌授权、背书或厂商 CAD 精度 |
| `docs/images/*` | 本项目规划图和界面截图 | 场景、UI 为项目成果；截图中嵌入的第三方商品图／装饰画不自动获得 MIT 许可 |

商品来源索引为 `docs/research/asset-index.json`。有 `photoSource` 的记录保留直接图片来源；没有该字段的早期条目只保留商品页，并明确“原始图片 URL 未记录”。不能据此推断全部图片都已获得发布授权。

`npm run build:public` 不复制 `products/`，商品照片改为占位图。它只是可公开审阅的去照片构建选项，不会自动清理仓库源码或 README 截图。公开托管前仍需核对拟发布文件的素材范围。

包内不需要也不应加入账号 Cookie、验证码、浏览器个人资料、消费者个人评论信息、绝对本机路径或用户临时图片缓存。已有选品记录保留商品事实和不确定性，未打包原始登录会话。

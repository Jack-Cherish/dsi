## 过程中出现的问题与改法

- **模型与照片不一致：** 通用沙发分支无法表达不同脚架、扶手和靠垫，改为按照片特征建立专用模型；剩余类别分支仍可能近似。
- **毛巾过大：** 混淆商品展开规格和叠放后的模型包络。以后记录两套语义，未核维度明确标注。
- **走不进浴室：** 陈设或植物挡在通道。默认场景先保证通行，再补装饰；空间不足时撤掉该实例而不是删除商品库条目。
- **墙面一半颜色不同：** 单个墙片改色不能代表整间装修。新增房间墙面分组和整间应用。
- **皮革/木纹过假：** 法线强度、粗糙度和反射光照需要一起调整，不能只给一个平面贴图。
- **“同款”证据不足：** 外形相似不代表同品牌同型号；把近似款、未核尺寸与未读评论写在商品记录。
- **打包后文件丢失：** 源码原本依赖工作目录与相邻脚本。此次加入独立根目录、资源适配和锁定依赖版本。

## 明确没有做的事

没有加入京东账号或验证脚本；没有声称完成全部商品精确 3D 扫描；没有自动保持价格最新；没有把程序化近似模型叫做厂商模型；没有创建或推送远端 GitHub 仓库。
